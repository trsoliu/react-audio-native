# Public Agent instructions

This knowledge base documents React Audio Native for React DOM and WebViews. It is not a React
Native native SDK. Preserve the shared `@trsoliu/audio-core` state contract, SSR-safe imports,
StrictMode cleanup, capability detection and protocol-neutral Bridge boundary.

Begin with the project map and relevant architecture, compatibility or release page. Treat generated
package declarations and current tests as authoritative for exact signatures. Stay read-only unless
the user explicitly authorizes a bounded write. Never infer authority to publish packages, merge
branches, change repository settings or mark device smoke evidence complete.

Do not expose secrets, registry credentials, private endpoints, local absolute paths or unpublished
device artifacts.
