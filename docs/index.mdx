## 这套文档解决什么问题

React Audio Native 把 `@trsoliu/audio-core` 的浏览器媒体契约映射为 SSR 安全的 React
组件、Headless Hook 和命令句柄。文档同时覆盖 WebView 能力、Bridge 边界、跨仓库发布
顺序和真机证据。

使用者从[快速开始](./guide/getting-started/)进入；维护者先看[项目地图](./project-map/)和
[React 架构](./wiki/architecture/)；AI 客户端读取构建生成的
`/.well-known/silen/manifest.json`，并保持只读直到用户明确授权写入。

## 当前发布状态

- `@trsoliu/audio-core@1.0.0` 已发布；React 稳定候选精确依赖该稳定核心，发布后将由
  `react-audio-native@1.0.0` 的 `latest` 标签提供，并通过 OIDC Trusted Publishing 携带 provenance。
- 包面向 React DOM 18.2/19、移动浏览器与 WebView，不包含 React Native 原生 SDK。
- 稳定 `1.0.0` 已由维护者的版本绑定自动化评估授权；未执行的宿主真机场景及剩余风险在
  [兼容性评估与真机记录](./device-smoke/)中如实保留。
